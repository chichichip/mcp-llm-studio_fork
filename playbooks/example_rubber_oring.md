# Rubber O-ring 선정 실행 시트

> ⚠ **이 파일은 형식 설명용 예시다.** 규격 번호·온도 범위·엑셀 경로는 사내 지침서
> 원문으로 **반드시 교체**하고, 교체한 뒤 `run_standard_server.bat --lint`로 점검할 것.
> 실제로 쓸 시트는 사내 AI에게 지침서를 읽혀 만든 뒤 이 폴더에 넣는다
> (만드는 법은 `playbooks/README.md`).

## Step 1. 입력 조건 확보

설계 요구조건에서 아래 값을 확보한다. **추측하지 말고 사용자/설계 조건표에서 받는다.**
값이 사양서에만 있으면 아래 도구로 찾아서 확인한 뒤 제출한다.

```입력
작동유체 | choice: Air, Fuel, Oil, Exhaust | 필수
작동온도_min | number(°C) | 필수 | 정상운전 최저 온도
작동온도_max | number(°C) | 필수 | 과도 상태 포함 최고 온도
작동압력 | number(bar) | 필수 | psi/MPa로 받아도 bar로 자동 환산된다
장착방식 | choice: Radial, Axial | 필수 | 플랜지 홈이면 Axial
모재 | text | 필수 | 상대 금속 재질. 예: Inconel 718
```

```도구
docs__search_docs — 작동 조건이 사양서/설계 요구서에만 있을 때 찾는다
office__read_excel_range — 설계 조건표가 엑셀로 관리될 때 읽는다
pdf__read_pdf_text — 조건이 DRM PDF 사양서에 있을 때 읽는다
```

## Step 2. 기본 사양(AS83485) 적용 가능성 판단

기본 사양을 그대로 쓸 수 있는지 먼저 본다. **온도·유체 두 조건을 모두 만족할 때만**
기본 사양이고, 하나라도 벗어나면 Step 3에서 대체 규격을 고른다.

⚠ 지침서 원문 확인 필요: 규격 표기가 `AS83485`/`AS834485`로 섞여 있었다. 온도 상·하한
(-30 ~ 204 °C)과 허용 유체(Air/Fuel/Oil)도 원문 값으로 재확인할 것.

```판단
조건: 작동온도_min >= -30 and 작동온도_max <= 204 and 작동유체 in [Air, Fuel, Oil]
참 -> 선정규격=AS83485; 기본 사양 적용 가능 — Step 3에서 Dash No.만 결정한다; 다음=3
거짓 -> 기본 사양 적용 불가 — Step 3에서 대체 규격표 매칭부터 한다; 다음=3
```

## Step 3. 선정 규격 확정 및 Dash No. 결정

- `선정규격`이 이미 **AS83485**로 기록돼 있으면 대체규격표는 **보지 않는다.** Dash No.만 정한다.
- 비어 있으면 아래 대체규격표에서 **작동 조건에 맞는 규격 1개**를 고르고 `선정규격`으로 기록한다.
- Dash No.는 자동화 도구가 없다. **선정한 규격의 사양서(Dash No. 표)를 찾아** 단면 지름·내경이
  장착부 치수에 맞는 Dash를 고른다. 근거(문서명·표 번호)를 note에 남긴다.

```표 대체규격표
| 규격 | 적용 조건 | 비고 |
| --- | --- | --- |
| AS83485 | -30 ~ 204 °C, Air / Fuel / Oil | 기본 사양 ⚠ 범위는 지침서로 확정 |
| AS3569 | 고온 (204 °C 초과) ⚠ 지침서 값으로 교체 | 예시 행 |
| AS9386 | Exhaust 등 기본 사양 밖 유체 ⚠ 지침서 값으로 교체 | 예시 행 |
```

```도구
docs__search_docs — 선정한 규격의 Dash No. 표를 찾는다. 예: "AS83485 dash number 표 단면지름"
pdf__read_pdf_text — 규격 사양서가 DRM PDF일 때 해당 페이지를 읽는다
```

```기록
선정규격 | 최종 선정한 규격 번호
dash_no | 선정한 Dash No. (예: 214)
dash_근거 | Dash를 고른 근거 — 문서명·표·해당 치수
```

## Step 4. 장착부(그루브) 치수 설계

사내 자동화 통합문서에 Dash No.를 넣어 그루브 치수를 뽑고 도면에 반영한다.
**장착방식에 따라 시트가 다르다** — 아래에서 자동으로 골라 준다.

```엑셀
파일: C:\표준품\MD-WI-004-6-10.xlsx   ⚠ 실제 경로로 교체
시트: 장착방식 == Radial -> Sheet2 ; 장착방식 == Axial -> Sheet3
조회키: dash_no
추출: 그루브_폭, 그루브_깊이, 그루브_내경, 모따기
도구: office__read_excel_range
```

```기록
그루브_폭 | mm
그루브_깊이 | mm
그루브_내경 | mm
모따기 | mm, 없으면 '해당없음'
도면반영 | 도면 번호와 반영 여부
```

## Step 5. 최종 검증

아래를 하나씩 확인하고 결과를 note에 적는다. 하나라도 걸리면 back_step으로 돌아가
해당 단계를 다시 한다.

```검증
선정 규격의 허용 온도 범위가 작동온도_min ~ 작동온도_max를 모두 덮는가
선정 규격이 작동유체에 대해 사용 가능한가 (재질 적합성)
작동압력이 해당 Dash/장착 방식의 허용 압력 이내인가 (백업링 필요 여부 포함)
그루브 치수가 자동화 엑셀 출력값과 도면 기입값이 일치하는가
상대 모재와의 접촉·갈바닉 부식 문제가 없는가
```

```기록
검증결과 | 합격 / 조건부합격 / 불합격
```
