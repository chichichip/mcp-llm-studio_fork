# spec-reader

항공 가스터빈 표준품(체결류) 선정 에이전트의 **스펙 판독 모듈**.

## 최종 목표 (이 저장소는 그중 1단계)

```
사용자: "BOLT, DOUBLE HEX, 직경 .190 / 스레드 길이 XX"
  → 엑셀 표준품 목록에서 볼트 도면번호 확정
  → 볼트 스펙 PDF 판독 → dash 확정
  → 같은 중분류의 너트 도면번호 확정
  → 너트 스펙 PDF 판독 → 나사 맞는 dash 확정
출력: 볼트 부품번호 + 너트 부품번호
```

이 저장소는 **"스펙 PDF 판독"** 부분만 담당한다. 엑셀 검색과 짝 매칭은 후속 모듈.

## 환경 제약 (중요)

- **개발은 외부망, 실행은 사내망.** 코드만 수동 반입한다.
- **사내망에서 어떤 파일도 반출 불가.** 실행 결과는 사람이 눈으로 보고 구두 전달.
  → 그래서 실행 출력은 **구두로 옮길 수 있을 만큼 짧아야 한다.** 장문 JSON 덤프 금지.
- 외부망에는 VLM 엔드포인트가 없다. 개발 중 검증은 `fixtures/` 의 정답 데이터로 한다.
- VLM 은 사내 호스팅 Gemma. OpenAI 호환 `/v1/chat/completions`, 인증 헤더 없음.

## 도메인 사실 (조사로 확정된 것)

### 1. dash 번호의 의미가 표준마다 다르다 ★

| 표준 | dash 의미 | 나사규격 |
|---|---|---|
| MS9555 | **길이** (-02~-30) | .164-36 고정 |
| MS9556 | **길이** (-03~-45) | .190-32 고정 |
| AS3477 | **나사규격** (-08=.1640-36, -09=.1900-32) | dash 마다 다름 |

→ 부품번호만 보고 치수를 추론하면 안 된다. 반드시 표를 읽어야 한다.

### 2. dash 번호는 단조가 아니다

MS9555: -26(1.750) → -27(1.875) → -28(2.000) → **-29(1.812)** → -30(1.938)
후에 추가된 dash 가 빈 칸을 메운다. "단조 증가" 를 검증 규칙으로 쓰면 오탐.
대신 "L 이 1/16" 격자 위" 를 쓴다.

### 3. L - K_max 가 계열 상수다 (핵심 검증 규칙)

- MS9555: **0.578** (dash -09 이상)
- MS9556: **0.630** (dash -10 이상)

나사부 길이가 설계 상수이고 그립(K)이 길이 변화를 흡수하는 구조.
→ 이 값에서 벗어나는 행 = 판독 오류.
단, 짧은 dash(MS9555 -02~-08, MS9556 -03~-09)는 K 가 고정이라 그립이 없고
상수에서 벗어난다. 최빈값 기준으로 판정해야 예외가 자동 분리된다.

### 4. 표가 좌우 여러 그룹으로 쪼개져 있다

한 페이지에 같은 헤더가 2~3번 반복되며 dash 구간이 나뉜다.
프롬프트에 이걸 명시하지 않으면 VLM 이 첫 그룹만 읽고 끝낸다.

### 4-1. 식별 컬럼명이 표준마다 다르다

MS9555/9556 = "DASH NUMBER", AS3477 = "PART NUMBER", AS4395 = "SIZE CODE".
프롬프트에서 첫 컬럼을 무엇이라 부르든 `dash` 키로 통일해 받고,
원래 이름은 `id_column` 으로 별도 보고받는다.

### 4-2. 표가 여러 페이지에 걸친다

- 행 분할: 같은 표가 페이지를 넘어 이어짐
- 컬럼 분할: AS4395 처럼 TABLE 1A(sheet2) / TABLE 1B(sheet3) 가
  같은 부품의 다른 치수를 나눠 다룸

merge.py 가 둘 다 처리. 같은 칸을 두 페이지가 다르게 읽으면 충돌로 보고 -> 판독 오류 신호.

### 5. 짝(볼트↔너트) 규칙

**중분류가 1차 키, 나사규격이 2차 키.**
`BOLT, DOUBLE HEX` → `NUT, DOUBLE HEX` 중분류에서 고르고, 그 안에서 나사규격 매칭.
나사규격만으로 매칭하면 안 된다 (MS9556 ↔ MS20500 은 나사는 맞지만
MS20500 이 hex 라서 짝이 아니다).

### 6. 재질/온도

스펙 본문 REQUIREMENTS 문단에 있다(표 아님). MS9555/9556 = AMS5731(A286).
MS20500 은 제목에 1200°F 명시. 엑셀 소재 컬럼은 `A286` 같은 구체값과
`CRES` 같은 계열명이 섞여 있어 필터 키로 쓸 수 없다.

## 엑셀 표준품 목록 구조 (후속 모듈용)

| 컬럼 | 예시 |
|---|---|
| 대분류 | BOLT |
| 중분류 | BOLT, DOUBLE HEX |
| 도면번호 | AS9555 ← **스펙 파일명과 동일** |
| 부품번호 | MS9555-07 |
| 품명 | BOLT, DOUBLE HEX, 0.164 |
| 소재 | A286 / CRES |
| 비고 | - |

스펙 파일명 = 도면번호 → 검색 불필요, 결정론적 조회 가능.

## 아직 안 정해진 것

- "스레드 길이 XX" 의 판정식. 현재는 **직접 비교**로 구현.
  추후 체결두께 기반 2.5산 역산으로 바뀔 수 있음 → `select.py` 로 분리해 둘 것.
- 너트 표의 알파벳 치수 의미 (C/H/N/T/W). 도면을 봐야 확정.
- 나사규격형 표준(AS3477 류)이 전체에서 몇 개인지.

## 개발 원칙

- **VLM 은 판독만.** 선정 판단은 결정론적 함수로. 항공 부품이라 환각은 치명적.
- **판독값은 자동 검증 통과 후에만 사용.** 검증 규칙은 `verify.py`.
- **모름은 모른다고 출력.** 후보 0개, 판독 실패, 키 미확정 시 추정 금지.
- 출력은 짧게. 사내망에서 사람이 읽고 옮겨야 한다.
